# Memory

Usual servings when the user does not give a count or size:

- If I just say eggs, it's usually egg md x2.
- If I just say shrimp, it's shrimp small, and the skill adds `* 8`.
- If I say milk, I usually mean the Lactaid milk with two asterisks `**`.
- If I say cereas or Cheerios, I mean the Cheerios with two asterisks `**`.

Paste these:

- eggs → `Egg md x2`
- shrimp → `Shrimp sm x 1 * 8`
- milk → `Lactaid whole milk ¾ cup**`
- cereas → `Cereal - Cheerios 1½ cups**`
- Cheerios → `Cereal - Cheerios 1½ cups**`
